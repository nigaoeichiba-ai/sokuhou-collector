## 疑問の出し方
- 一人につき5つ前後。その人の立場で、本当に聞きたいことを、その人の言葉で書く(「これを知りたい」「このことが書いていない」「これは本当?」「私のケースとは少し違う」「結局どうしたらいい?」「よい○○を探す方法は?」「私の地域だとどうなの?」「別の方法のほうがよいのでは?」など)。
- 記事にすでに答えが書いてある疑問は出さない(書いてあっても分かりにくければ出してよい)。
- 疑問ごとに、次の4つを付ける。
  - action: その人が取れる行動(一言)
  - answer_type: 1=公的資料で確認できそう / 2=一般的な考え方で答えられる / 3=個人差・地域差がある(調べ方を示す) / 4=記事で答えない方がよい(相談先を示す)
  - place: 節(この記事の中) / 別ページ / 連載 / チェックリスト / 計算ツール / 質問と答え
  - search: answer_type が1のとき、どの役所・機関の資料を見れば確かめられそうか(一言。分からなければ空)

出力は、次の形の JSON だけにしてください。
{"personas": [{"who": "契約前の人", "situation": "その人の状況を一文", "questions": [{"q": "疑問", "action": "取れる行動", "answer_type": 1, "place": "節", "search": "国民生活センター"}]}]}
