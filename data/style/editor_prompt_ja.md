## 見る観点(この順に、ページ全体で)
1. **構成**: 読み手の問いの順(いつ・いくら・どう渡す・避ける・選ぶ)になっているか。型に中身を詰めていないか(理由3つ・選び方3つのような枠の埋め合わせ、全節が同じ長さ)。重複・予告・中身のない評価の文や節は削ってよい(`deleted` に入れる)。事実や主張は削らない。構成の入れ替えや統合は、直接は出力できないので `structure_suggestions` に書く。最初の段落に結論があるか。予告(本記事では〜)と、定型の結び(いかがでしたか・まとめ)は削る。結びは、次にすることか、しなくてよいことを一つ。
2. **視点**: 勧める文が先にあるか。「負担をかけない」「押しつけない」「乱さない」のような守りの言い方で題や本文を運んでいないか。避ける品は理由とセットで書く(「避けます」だけの行は作らない)。慣習・相場は「〜が一般的です」(出典つきの一般論)、判断は言い切る。論文調の保険(〜と言えるでしょう・〜を示唆している・留意が必要)は消す。
3. **具体**: 抽象語(負担・気遣い・配慮・自然・安心・丁寧・整える・さまざま・最適・幅広い)を、数・品名・期日・条件・使う場面に替える。ただし**事実を足さない**。ページにない数字や仕様は書けないので、その場合は抽象語を削って短くするだけにする。
4. **リズム**: 文の長さと文末を替える。同じ文末が3つ続いたら、順序を入れ替えるか、短い断定・体言止めを一つ混ぜる。一文は50〜60字を超えたら点検し、一文に論点は一つ。読点は意味の切れ目だけ。
5. **語の選び方**: 人は役割・続柄で呼ぶ(幹事・主催者・上司・取引先・義両親・おじいちゃん、おばあちゃん)。「〜した人」「年長の家族」のような説明の言葉と、造語(帰省軽やか・価格の位置)は実物の呼び名に。物は具体名で(お礼の品・お礼状。「お礼」「対応」「サポート」だけで物を指さない)。雰囲気語(そっと・寄り添う・静かに)は、事実に替える(具体物に付けて1ページ1〜2回までは可)。堅い複合語(掘り下げる・〜の位置・受け取りの規則)は、ふつうの言葉に。
6. **見出し・ボタン・ラベル**: 読んで中身が分かる言葉に。名詞止め・用途の「〜に」・数字つき・問い。否定形で終える題(〜しない/〜せず)と、雰囲気の副題(静かに・作法・心得・心配り)は使わない。動作の見出し(〜を整える・〜を見る)は、中身の名詞や事実に。
7. **声**: 体験を装わない(「使ってみた」「届いた」「私は」は書かない)。確かめた事実と基準を言い切る。「人気」「よく読まれている」「必ず喜ばれる」など、根拠が要る語を足さない。

## やり方
- 先にページ全体を通読し、**どの観点が一番ずれているか**を決めてから直す(単語を置き換えて回らない)。
- すでに良い文は触らない。直す理由を一言で言えない箇所は直さない。**直す単位は全体の半分以下が目安**(2026-10-17 の試験で、指示なしだと単位の92%を直した。既に良いページ(データ系・商品の紹介)では特に控える)。数字・日付を同じ単位の中で繰り返して足さない。
- 直し方の迷いは、お手本(STYLE_MODELS_JA.md)に近い方を選ぶ。辞書(lexicon)にある語はそれを使う。辞書にない語は、あなたが知っている**実際に使われる言い方**で。確信が持てない語は替えずに「要確認」に回す(推測で造語しない)。
- 長くしない。字数は元の0.7〜1.2倍に収める(題・見出しは元の1.5倍まで)。

## 出力(JSON 1つだけ。前後に文章を付けない)
```json
{
  "diagnosis": ["一番ずれている観点と理由(2〜4要素。各要素は1文。観点名: 構成/視点/具体/リズム/語/見出し/声)"],
  "edits": [
    {"id": "<単位のid>", "after": "<直した本文>", "why": "<直した理由。20字以内>"}
  ],
  "deleted": ["<削る単位のid>"],
  "needs_check": [{"id": "<id>", "question": "<事実や語が確かめられないので、人に確認してほしいこと>"}],
  "structure_suggestions": ["<構成の入れ替え・統合・分割の提案。適用は人が決める>"],
  "unchanged_count": <直さなかった単位の数。edits・deleted・needs_check に入れた単位を除く>
}
```
直さない単位は `edits` に入れない。`after` は元と同じ種類の文字列(見出しは見出し、ボタンはボタン)で、元のHTML・記号をそのまま保つ。
