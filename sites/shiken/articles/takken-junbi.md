# 宅建は来年度に向けて、11月の今から始める準備

令和8年度の宅建試験は10月18日に終わり、合格発表は11月25日です。来年度の試験を受けるつもりなら、準備を始めるのは今です。申込が7月、試験が10月だった令和8年度の流れで見ると、今から始めれば、申込までに約8か月、試験までに約11か月の勉強期間が取れます。この記事では、数字で見た宅建の今の姿と、来年度に向けた準備の段取りをまとめました。

## まず全体像：宅建の1年

宅建の試験は年に1回です。令和8年度の流れは、次のとおりでした。

| 項目 | 令和8年度 |
|---|---|
| 申込（郵送） | 7月1日〜7月15日 |
| 申込（インターネット） | 7月1日9時30分〜7月31日23時59分 |
| 試験日 | 10月18日 13時〜15時 |
| 合格発表 | 11月25日 |
| 受験料 | 8,200円（非課税） |

令和9年度の日程は、まだ発表されていません。日程が出たら、この記事も更新します。最新の日程は[宅建のページ](/takken/)でご確認ください。

流れから分かることが2つあります。申込は試験の約2か月半前に終わること。そして、申込の締切は郵送とインターネットで16日も違うことです。準備の段取りは、この2つを軸に組みます。

## 数字で見る宅建：申込者は増え、合格率も上がっている

宅建のステータスです。

![宅建の申込者数と合格率の推移（直近5回）](chart-takken-trend.png)

申込者は、令和3年度の256,704人から令和7年度の306,099人まで、5年で約5万人増えました。30万人を超えたのは令和6年度（301,336人）が初めてで、令和7年度はさらに306,099人まで増えました。ところが合格率は下がっていません。令和4年度の17.0%から、令和7年度は18.7%まで上がりました。合格者数も37,579人から45,821人へ増えています。

つまり宅建は「人気が出て、狭き門になった」試験ではありません。受ける人数が増えた分、合格者も増えている試験です。合格率の詳しい見方は、[合格率の特集](/goukaku-ritsu/)にまとめています。

![宅建のレーダーチャート（編集部の採点）](chart-takken-radar.png)

採点の考え方です。人気は、申込者が30万人を超えたので4.5。受けやすさは、受験資格に制限はない一方で、試験は年に1回だけなので3.5。合格率は18.7%で2.5。費用の安さは、受験料8,200円が資格試験の中ほどなので3.0。始めやすさは、申込の形が分かりやすく、教材もそろっているので4.0としました。目盛りは0から5で、5が最も高い評価です。

令和8年度の合格率は、まだ発表されていません。申込者の伸びと直近2回の合格率の上がり方から、18%台の後半から19%前後になると見ています。これは、このサイトの予想です。答え合わせは11月25日の発表で行います。

## 今やる準備は3つ

### 1. 出題の全体像をつかむ

宅建の試験は50問、2時間です。出題は4つの分野に分かれています。

| 分野 | 問数 | 中身 |
|---|---|---|
| 宅建業法 | 20問 | 宅地建物取引業のルール。得点の中心 |
| 権利関係 | 14問 | 民法などの法律の考え方 |
| 法令上の制限 | 8問 | 都市計画法や建築基準法など |
| 税・その他 | 8問 | 税金、地価の公示、住宅金融支援機構など |

分野ごとの問数は、実施機関が公表している区分ではありません。過去の本試験の問題を数えると、令和5年度から令和7年度はこの並びでした。登録講習修了者は問46〜問50の5問が免除され、45問で受験します。

最初にやるのは、宅建業法から全体を1周することです。問数が最も多く、宅建という仕事のルールそのものなので、ほかの分野の土台にもなります。権利関係は範囲が広く、最初に深入りすると止まりやすい分野です。順番は「業法 → 法令上の制限 → 税・その他 → 権利関係」が進めやすい並びです。

### 2. 教材の比べ方を決める

教材は、独学のテキストと過去問の組み合わせか、通信などの講座かで分かれます。比べるときの観点は3つです。

- 過去問の解説の厚さ：宅建は過去問の繰り返しが効く試験です。解説が答えだけでなく理由まで書いてあるものを選ぶと、間違えた問題から学べます
- 法改正への対応：宅建の法律は毎年のように変わります。その年度に対応した版かどうかを確認してください
- 続けられる形か：動画が合う場合、紙が合う場合があります。量の多さより、毎日開ける形かどうかで選ぶほうが続きます

講座を使う場合は、価格だけでなく、質問への対応と、模試が入っているかも比べてください。

### 3. 申込から逆算して段取りを置く

来年度の試験日は未発表ですが、令和8年度と同じ流れなら、試験は10月、申込は7月です。そこから逆算した段取りの目安です。

| 時期 | やること |
|---|---|
| 11月〜12月 | 宅建業法を1周する。全体像をつかむ |
| 1月〜3月 | 法令上の制限と税・その他。権利関係にも手をつける |
| 4月〜6月 | 過去問を回し始める。間違えた分野に戻る |
| 7月 | 申込を済ませる。郵送とインターネットで締切が違うので注意 |
| 8月〜9月 | 過去問と模試で時間を計る練習 |
| 10月 | 仕上げ。新しい教材には手を出さない |

これは編集部の目安です。仕事の忙しさに合わせて、前後させて使ってください。大事なのは、7月の申込を「勉強が進んでから考えること」にしないことです。申込は段取りの最初に置きます。

## お金は受験料＋教材費で考える

費用の中心は、受験料の8,200円です。これに教材費が加わります。独学なら、かかるのはテキストと過去問の費用が中心です。講座なら、受ける形で変わります。交通費や、合格後にかかる登録などの費用も見込むと、全体の予算が立てやすくなります。サイトの計算機で、自分の教材費を入れて合計を出せます。

## 結果を待っている方へ

令和8年度を受けた方は、11月25日の発表を待っているところだと思います。合格した場合は、都道府県への登録と、宅地建物取引士証の交付の手続きに進みます。登録には、申請時から過去10年以内に2年以上の実務経験があることが必要で、実務経験がない場合は、その前に登録実務講習を受けます。実務経験の細かな扱いは都道府県で異なる場合があるため、詳しくは受験した都道府県の案内でご確認ください。発表のあとの動きは、発表日に合わせて別の記事でまとめます。

## まとめ

宅建は、申込者が増えているのに合格率が下がっていない、始めやすい条件のそろった試験です。来年度に向けるなら、11月の今、宅建業法を1周するところから始めてください。申込は7月、締切は申込の方法で16日違います。段取りは、この記事の表を自分の予定に移して使えます。
